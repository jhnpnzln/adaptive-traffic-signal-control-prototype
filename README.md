# Modifying Stoplight System through System Development using Adaptive Signal Control (ASC), YOLOv4, and Lighthill-Whitham-Richards (LWR) Traffic Flow Model

# React + TypeScript + Vite

This project/prototype was built using React + TypeScript + Vite for simulation. The purpose of this study is to lessen the burden of traffic congestion in the daily lives of commuters in Public Utility Vehicles (PUVs) and motorists by modifying the stoplight system through development of an Adaptive Signal Control (ASC) system.

# 🚦 Levels of Service (LOS)
### LOS A – Excellent
- Traffic moves freely
- Cars can go at the speed limit
- Little to no delay
  - 👉 Like driving on an empty road

### LOS B – Good
- Slightly more cars, but still smooth
- Minor delays
  - 👉 Comfortable driving

### LOS C – Fair
- Noticeable traffic
- Some delays, but acceptable
  - 👉 Typical city driving

### LOS D – Poor
- Heavy traffic
- Slower speeds and frequent delays
  - 👉 You start feeling frustrated

### LOS E – Very Poor
- Road is almost full
- Very slow movement
- Any small problem causes big delays
  - 👉 Traffic is on the edge of a jam

### LOS F – Failure
- Traffic jam
- Stop-and-go or complete standstill
  - 👉 Bumper-to-bumper traffic

### 🚗 Why LOS Is Important
- Helps engineers design roads
- Used by planners to evaluate intersections
- Helps decide when a road needs improvement
